# AI-VAPT Framework — Performance and Resource Baseline

## 1. Workload Specification
- Scan Target: Localhost controlled lab fixture / Juice Shop testbed
- Scan Modes: Quick / Full
- Provider Mocking: Local deterministic mock server (OpenAI, OpenRouter, Anthropic, Gemini, Ollama, Custom)
- Candidates Evaluated: Baseline 3-candidate GAP-1 queue, 5-candidate stress queue

## 2. Baseline Measurements (Pre-Optimization)
- Unbounded response body reads: `urllib.request.urlopen` reads unbounded `resp.read()` in `_analyze_probe` and scanners.
- Global process environment mutation: `runtime_credentials.py` syncs keys to `os.environ` causing global lock contention and cross-run leakage.
- Full trace rescanning: `reconciliation.py` performs multiple linear rescans of `decision_trace.jsonl` and full tool logs.
- Report export latency: Markdown/PDF/HTML generated by reading full run state without indexing.

## 3. Optimization Targets & Results
(Metrics will be recorded and updated during P4 implementation)
- Memory usage: Bounded response stream reading (max 1MB per probe).
- Concurrency: Thread-safe per-run isolated context instead of process-global locks.
- Latency: Indexed candidate lookup in reconciliation.
