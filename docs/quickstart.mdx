## Prerequisites

- Docker (running)
- Python 3.11+
- An LLM API key or local model endpoint (OpenAI, Anthropic, Google, Ollama, Cloud-Hosted, etc.)

## Installation

<Tabs>
  <Tab title="Clone & Run (Recommended)">
    ```bash
    git clone https://github.com/Vinit-Solanki16/ai_vapt_framework.git
    cd ai_vapt_framework
    uv pip install -e .
    ```
  </Tab>
  <Tab title="Pip / Virtualenv">
    ```bash
    pip install -e .
    ```
  </Tab>
</Tabs>

## Configuration

Set your LLM provider endpoint and model:

<CodeGroup>
```bash Cloud-Hosted / Custom OpenAI-Compatible
export AI_VAPT_LLM="cloud_hosted/kaggle-model"
export OPENAI_BASE_URL="http://127.0.0.1:8000/v1"
export LLM_API_KEY="your-api-key"
```

```bash OpenRouter
export AI_VAPT_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
```
</CodeGroup>

<Tip>
AI-VAPT also provides an interactive Web Operations Console at `ai-vapt web` for browser-based configuration and multi-engine assessment tracking.
</Tip>

## Run Your First Assessment

```bash
ai-vapt --target ./your-app
```

<Note>
First run initializes the autonomous sandbox environment. Assessment runs are stored in the local run directory.
</Note>

## Target Types

AI-VAPT accepts multiple target types:

```bash
# Local codebase
ai-vapt --target ./app-directory

# GitHub repository
ai-vapt --target https://github.com/org/repo

# Live web application
ai-vapt --target https://your-app.com

# Multiple targets (white-box testing)
ai-vapt -t https://github.com/org/repo -t https://your-app.com

# Targets from a file, one target per non-empty, non-comment line
ai-vapt --target-list ./targets.txt
```
